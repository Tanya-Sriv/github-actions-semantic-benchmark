This is the **release-ready candidate**, not yet the published v1.1.0 release.

Start with:

- `RELEASE_NOTES_v1.1.0_RC5.md`
- `PUBLIC_RELEASE_INCLUSION_AUDIT.md`
- `release_metadata/MANIFEST.csv`

The package preserves the scientific evidence added after v1.0.1 while keeping private/preliminary automated secondary-evaluation artifacts out of the public release.

The authoritative frozen human-evaluation originals are retained in the separate frozen-records master archive. This public candidate includes a sanitized derivative whose scoring content is unchanged and whose SHA-256 values are explicitly mapped back to the frozen originals.
