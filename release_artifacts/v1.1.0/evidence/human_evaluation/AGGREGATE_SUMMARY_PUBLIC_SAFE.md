# Independent Human Evaluation — Public-Safe Aggregate Summary

This release candidate includes a **public-sanitized derivative** of the frozen independent-human evaluation workbooks. The authoritative frozen originals remain preserved separately; the public files are hash-mapped back to them.

The automated secondary evaluation is a private preliminary artifact and is **not** represented here as independent human judgment.

## Verified final metrics

- Total responses evaluated: **315**
- Strict oracle match: **205/315 (65.08%)**
- Lenient oracle match: **226/315 (71.75%)**
- Claude strict: **85/105 (80.95%)**
- GPT strict: **81/105 (77.14%)**
- Gemini strict: **39/105 (37.14%)**
- Human/secondary four-category agreement: **303/315 (96.19%)**
- Cohen's kappa: **0.929**
- Claude-vs-GPT exact McNemar p-value: **0.625**

## Publication rule
The public-sanitized independent-human evaluation package is included and hash-mapped to the frozen originals. Do not include the private automated secondary-evaluation workbook as a replacement or describe it as independent human judgment.
